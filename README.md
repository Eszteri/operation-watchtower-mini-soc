# operation-watchtower-mini-soc

Overview
Operation Watchtower is a mini Security Operations Center (SOC) project built using Splunk Enterprise.

The environment includes:

Windows 11 endpoint
Linux server
nginx web server
Splunk Enterprise
Objectives
Centralized log collection
Security monitoring
Detection engineering
Dashboard creation
Attack simulation
Incident investigation
MITRE ATT&CK mapping
Features
Multiple security detections
Windows monitoring
Linux SSH monitoring
Web/nginx monitoring
Alerting and investigations
SOC playbooks
Threat hunting queries
Technologies
Splunk Enterprise
Windows Event Logs
Sysmon
Linux Syslog
nginx
MITRE ATT&CK
SPL (Search Processing Language)
